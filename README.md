A single-line roast of a smart fridge: after a 3 a.m. firmware update, the fridge holds your milk hostage until you accept its terms and conditions — the appliance that turned breakfast into a software license agreement.

## Run

```sh
node main.ts
```

This writes the one-line roast to `/output/entry.txt`.
